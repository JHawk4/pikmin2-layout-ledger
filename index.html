How lucky were the layouts?

Every cave sublevel's layout is set by the game's random number generator. This site reads that seed from the falling title letters in each Pay Off Debt run's video, rebuilds the exact layout, and asks how lucky the layouts were and how much time the runner saved beyond what the layouts gave.

  • Layout luck: seconds the run's layouts should save against the median layout of the same sublevels, by CaveGen's layout judge re-tuned on these runs' real times. Luck percentile: how many random runs it beats.
  • Runner beyond the layouts: seconds the runner saved against the median run on the same sublevels, after allowing for the layouts (so a bad layout is not counted against the runner), with pokos counted: 2 pokos = 1 second.
  • Negative is faster, as on splits. Seeds read is how many sublevels' seeds were read with confidence; only those count. Click a column to sort; open a runner for their layouts.
