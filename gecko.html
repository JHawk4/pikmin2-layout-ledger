Gecko code: play a run's layouts

Pick your copy of the game and a run. The code below makes every cave sublevel that run has a trusted seed for come out with the run's layout, so you can practise the same caves the runner had. Sublevels the run doesn't have (or whose seed wasn't read with confidence) stay random. Story mode only; challenge mode and 2-player battle are left alone. Each time it sets a sublevel's layout it plays a short sound (the "GO" from 2-player battle's card slot, as Meeo's set-seed code does).

Using it

Dolphin: right-click the game, Properties, Gecko Codes, Add New Code; paste the code (the first line, starting with $, is its name), save, and tick it. Cheats must be on: Config, General, Enable Cheats. Then start the game.

Nintendont (Wii or Wii U): download the .gct and copy it to codes/GPVE01.gct on your SD card or USB drive, then turn on Cheats in Nintendont's settings. On a Wii, the Wii version's .gct works with a cheat-code loader such as Gecko OS or USB Loader GX. Nintendont keeps cheats in a small space, so a run with many sublevels can be too long for it.

The layout is set each time the sublevel is made, so dying, leaving and re-entering, or reloading the cave gives the same layout again. Where the runner went through a sublevel more than once (All Treasures runners farm purple Pikmin in Bulblax Kingdom first), it is the layout of their first visit. Only the layout is fixed: enemies, eggs and anything else random after the sublevel loads behave as usual.

Versions

The versions marked untested use addresses from the Pikmin 2 decompilation's symbol maps; the USA release and the USA demo 1 build were also checked against real copies of the game. The Wii version (New Play Control!) has no decompilation; its addresses were found in a memory dump of the USA game and checked against an unmodified copy. If an untested one doesn't work for you, please say so in the suggestion box. Not supported:

  • Wii New Play Control! Europe and Japan (R92P01, R92J01): no copy of the game to find the addresses in yet
  • Any other build or a romhack: the addresses differ; the code would do nothing or crash
How it works

Pikmin 2 makes each sublevel from its global random number generator. This code hooks MapUnitGenerator::createMapPartsList (on both GameCube and Wii), just before the game's first draw for the layout (the same place as Meeo's set-seed code, whose seeds CaveGen uses). There it reads the cave and floor from the story mode section and, if the run has a seed for that sublevel, writes it into the generator's state and plays the sound. Seeds are the layout seeds this site shows on each run's page; the CaveGen3 links show what each one should look like. Details: docs/gecko-code.md.
